# Password Strength Checker

A simple command-line tool that evaluates the strength of a password based on five criteria: length, uppercase letters, lowercase letters, digits, and special characters.

## Usage

```bash
python3 checker.py
```

The program will ask for a password and return a verdict (Weak / Medium / Strong) with a score out of 5.

## Requirements

- Python 3
